# Screenshots for the video and README

Retaken 2026-10-10 at 390 px width, full page height, with the dark glass UI in css glass mode (`?glass=css`, the phone default; the liquidGL lens is opt-in with `?glass=liquid`), on a fresh server with the clean seed (`data/seed.json`, no rehearsal data, no `make demo-db`). The top bar is sticky and the tab bar fixed, so each appears once, at the viewport edges. Files are JPEG (quality 78) to keep the folder under 2 MB. Activity on screen was made through the UI in this order: Resident A reports at DR-DN-PUSA with a camera photo, the MCD official accepts and marks it done with an after-photo, Resident B confirms it, then Resident B sends a second report and the coordinator sends the same picture again so it is held. Camera and location were the browser's fake devices at the DR-DN-PUSA coordinates. The leaderboard therefore shows the real formula on two tasks, not a ranked agency.
